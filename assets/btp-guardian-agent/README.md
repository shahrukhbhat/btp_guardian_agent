# BTP Guardian

An AI-powered conversational agent that gives SAP BTP platform teams and FinOps stakeholders instant, natural-language visibility into their cloud consumption, costs, account topology, entitlements, and governance posture.

## Overview

Uses A2A Protocol, LangGraph, LiteLLM, and SAP Cloud SDK.

## Structure

- `app/main.py` - A2A server entry
- `app/agent_executor.py` - Request handling
- `app/agent.py` - Agent logic
